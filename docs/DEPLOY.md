## 1.5. Windows: самый простой путь (двойные клики, БЕЗ ввода паролей)

1. В PowerShell (на своём компьютере) вставьте ОДНУ строку — она скачает
   кнопки на Рабочий стол и создаст `sonic-creds.txt` с паролями
   (файл остаётся ТОЛЬКО у вас, в публичный репозиторий пароли не попадают):
   ```
   $u='https://raw.githubusercontent.com/samagon90/vpnStar/arena/01a05219-vpnstar/deploy/windows/'; foreach($f in 'sonic-launch.bat','sonic-launch.ps1','sonic-doctor.bat','sonic-doctor.ps1'){ iwr ($u+$f) -OutFile "$env:USERPROFILE\Desktop\$f" }; Set-Content "$env:USERPROFILE\Desktop\sonic-creds.txt" "DE_IP=185.125.102.135","DE_PASS=<пароль DE root>","DE_XUI_USER=<логин 3x-ui>","DE_XUI_PASS=<пароль 3x-ui>","RU_IP=87.249.49.204","RU_PASS=<пароль RU root>"
   ```
2. **Двойной клик `sonic-launch.bat`** — всё без паролей: настраивает
   немецкий 3x-ui → снимает Public Key → ставит сайт на русский.
   В конце — адрес сайта + Блокнот с логом (там токен админки).
   Первый запуск ставит модуль Posh-SSH (~1 мин).
3. Если что-то не так: двойной клик `sonic-doctor.bat` — диагностика
   обоих серверов в Блокноте, присылайте мне её.
4. Запасной путь (если Posh-SSH не установился): `de-3xui.bat` и
   `ru-site.bat` (ввод пароля руками, правым кликом).

После успеха смените пароли серверов в панелях хостеров и обновите
`sonic-creds.txt` (Блокнот → строки DE_PASS / RU_PASS).

## 2. КОМАНДА 1 — окно терминала НЕМЕЦКОГО сервера

Создаёт VPN-сервер VLESS+Reality на порту 443, генерирует Reality-ключи,
открывает порт панели для RU-сервера. **Ждём блок «ГОТОВО ✅» и копируем Public Key.**

```
curl -fsSL -o /root/xui-setup.sh https://raw.githubusercontent.com/samagon90/vpnStar/arena/01a05219-vpnstar/deploy/xui-setup.sh && bash /root/xui-setup.sh 12345678 12345678 87.249.49.204
```

Если «Вход не удался» → подождать 10 минут (панель блокирует после неудачных
попыток) и вставить ту же команду повторно.

## 3. КОМАНДА 2 — окно терминала РУССКОГО сервера

## 5. Если что-то сломалось

- Пришлите последние 15–20 строк окна, где ошибка (и укажите: Команда 1 или 2).
- Повторный запуск той же команды безопасен: скрипт обновится с GitHub и продолжит.
- Полезные диагностики:
  - RU: `pm2 logs sonicvpn --lines 50`, `caddy version`, `node -v`
  - DE: `x-ui settings`, `ufw status`

## 6. После запуска (не срочно)

- **Домен**: reg.ru (купить `sonicvpn.ru`, МИР/СБП) → Cloudflare (A-запись → RU IP)
  → на RU: `nano /opt/sonicvpn/server/.env` (BASE_URL=https://sonicvpn.ru) → `pm2 restart sonicvpn`.
  Caddy сам получит HTTPS-сертификат (домен уже прописан в Caddyfile).
- **Платежи**: самозанятость (Госуслуги/Мой налог) → ЮKassa → в .env:
  `PAYMENT_MODE=yookassa` + `YOOKASSA_SHOP_ID` + `YOOKASSA_SECRET_KEY` → `pm2 restart sonicvpn`.
- **ИИ-поддержка**: console.groq.com (бесплатно, без карты) → ключ gsk_... →
  в .env: `AI_API_KEY=gsk_...` → `pm2 restart sonicvpn`.
- **TG-бот**: BotFather → токен → в .env: `TG_BOT_TOKEN=...` → `pm2 restart sonicvpn`.
