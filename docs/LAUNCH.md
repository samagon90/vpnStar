# 🚀 Sonic VPN: запускаем с нуля (объясняю на пальцах)

> Этот документ для человека, который НИКОГДА не работал с серверами.
> Каждый шаг: **что это → что нажать → что вписать → как проверить**.
> Время: 2–4 часа работы + ожидание одобрения самозанятости (параллельно).
> Деньги: ~400–900 ₽/мес, все оплаты — картой РФ (МИР) или СБП.

## Часть 1. Что мы вообще строим (на пальцах)

У нас готовый интернет-сервис из 5 кусков. Вот что такое каждый кусок:

| Кусок | Это | Почему нужен |
|---|---|---|
| **VPS (два сервера)** | Арендованные компьютеры в дата-центрах, работают 24/7. **RU-сервер** (Россия, ~150–300 ₽/мес, Timeweb/Beget) и **DE-сервер** (Германия, ~400–700 ₽/мес, Aéza) — покупаем у продавцов, которые **не просят документы**, оплата МИР/СБП | RU-сервер: сайт + база клиентов (данные в РФ, 152-ФЗ). DE-сервер: только VPN (сервер обязан быть за рубежом) |
| **VPN-софт (3x-ui)** | Бесплатная программа на DE-сервере, которая выдаёт людям «ключи» для подключения VPN | Это и есть сам VPN. У каждого клиента свой ключ |
| **Сайт sonicvpn.ru** | Наш лендинг + личный кабинет + админка. Живёт на **RU-сервере** | Люди покупают VPN здесь, получают QR-код для подключения |
| **Домен** | Адрес `sonicvpn.ru` (как «улица и номер дома»), ~250 ₽/год | Чтобы сайт открывался по красивому адресу, а не по цифрам IP |
| **Cloudflare** | Бесплатная «защита-курьер» между посетителем и нашим VPS | (1) сайт открывается быстро и в РФ, даже если что-то блокируют; (2) реальный адрес VPS прячется от блокировщиков |
| **Telegram-бот** | Бесплатный чат-бот (Telegram ничего не стоит) | Люди покупают VPN, получают QR, спрашивают поддержку — прямо в Telegram |
| **Нейросеть поддержки** | «Мозг» бота. Арендуем бесплатно у компании Groq | Бот отвечает на вопросы клиентов как живой консультант |
| **ЮKassa** | Платёжный терминал (как эквайринг): принимает **СБП** от клиентов и перечисляет деньги вам (нужен статус самозанятого) | Чтобы люди платили QR-кодом из приложения банка, а деньги падали на ваш счёт |
| **.env файл** | Текстовый файл на VPS со всеми «секретными ключами» (от платежей, бота, нейросети) | Программы читают его и понимают, куда подключаться |
| **pm2** | Маленькая программа-«староста»: если сайт упадёт — сам его поднимет | Чтобы ночью не просыпаться |

**Схема одним взглядом:**

```
Покупатель (РФ, телефон)
   │  1. открывает sonicvpn.ru  ←→  Cloudflare (бесплатно, прячет сервер)
   │  2. платит СБП-QR           ←→  ЮKassa → деньги ВАМ
   │  3. сканирует QR-профиль    ←→  VPN-сервер 3x-ui на DE-сервере (Германия)
   │  4. пишет в бота            ←→  нейросеть Groq (бесплатно)
   ▼
Два сервера:
  • RU-сервер (Россия, ~150–300 ₽/мес) — сайт, база клиентов, бот, админка
  • DE-сервер (Германия, ~400–700 ₽/мес) — только VPN
  Данные клиентов — в РФ (152-ФЗ), VPN-трафик — за границей. Итого ~800 ₽/мес.
```

## Словарь (если слово непонятно — перелистни сюда)

- **IP-адрес** — «телефонный номер» компьютера в интернете, выглядит как `185.14.23.107`.
- **SSH** — способ «сесть внутрь» удалённого компьютера через текст: вы печатаете команды, как в обычном терминале. На Windows 10/11 есть встроено (программа PowerShell).
- **Терминал** — чёрное окно, куда печатают команды. Windows: нажать `Win` → написать `powershell` → Enter.
- **Команда** — одна строчка текста в терминале (например `cd /opt/sonicvpn`). В этом документе команды в рамочках — копируйте их целиком.
- **nano** — простой текстовый редактор прямо в терминале (в нём редактируем .env). Управление: стрелки — движение, `Ctrl+O` → `Enter` — сохранить, `Ctrl+X` — выйти.
- **Токен / API-ключ** — длинная строка-пароль, по которой наш код узнаётся у чужого сервиса (Telegram, Groq, ЮKassa). Хранится только в .env, никому не показывать.
- **Webhook** — «звонок»: когда клиент оплатил в ЮKassa, она сама «звонит» нашему сайту, и тот активирует VPN. Настраивается один раз.
- **NS-записи (nameservers)** — два адреса вида `xxx.ns.cloudflare.com`, которые говорят интернету «домен sonicvpn.ru обслуживает Cloudflare». В Cloudflare их увидим, в reg.ru впишем.
- **Прокси (в Cloudflare)** — «оранжевое облако» у DNS-записи: включает защиту/CDN. У наших A-записей — ВКЛ.

## Часть 2. Шаги

### Юридика: что важно знать (5 минут, читайте один раз)

Коротко: **продавать VPN в РФ законно**, использовать — тоже (штрафов за использование нет).
Но есть 4 правила, которые мы соблюдаем:

1. **Платёж — «по белому»**: самозанятый (шаг 0) + ЮKassa. Чек у клиента, налог 4–6%, лимит 2,4 млн ₽/год.
2. **Не рекламируем «обход блокировок»** (запрещено законом; штрафы от 50 000 ₽). Сайт говорит про
   «безопасность, приватность, доступ в интернет» — формулировки уже проверены и безопасные.
   В рекламе/постах/в TG-канале пишем то же самое.
3. **Персональные данные граждан РФ — в России** (152-ФЗ). Наши данные клиентов (логины, email,
   TG-привязка, оплаты) лежат в базе на сервере. **Чистый вариант**: база+сайт+бот — на российском
   VPS (дешево, ~150–300 ₽/мес), а VPN-сервер (3x-ui) — в Германии (там он и должен быть).
   Один сервер за границей = формальный пробел (на практике мелкие провайдеры так живут,
   но «чистый» вариант стоит +200 ₽/мес — берём его).
4. **Техническая реальность** (не юридика): РКН блокирует VPN-сервисы по IP/протоколам
   (к марту 2026 — уже 469 сервисов; WireGuard/OpenVPN фильтруются). Поэтому:
   - у нас **VLESS+Reality на порту 443** (самый устойчивый к блокировкам протокол),
   - сайт за Cloudflare (IP сервера скрыт),
   - при необходимости потом добавим 2–3 VPN-сервера для ротации IP (гайд — в PLAN.md).

> Итог: самозанятость + ЮKassa + нейтральные тексты + данные в РФ + Reality-протокол =
> законная работа, как у dedVPN/24hype и других открытых сервисов.

### Шаг 0. Самозанятость (сегодня, 15 минут, телефон)

**Зачем:** без статуса самозанятого ЮKassa не примет деньги от клиентов. Одобрение идёт до 5 рабочих дней — поэтому стартуем СЕГОДНЯ, пока разворачиваем остальное.

1. Телефон: приложение **«Мой налог»** (App Store / Google Play / RuStore).
2. «Зарегистрироваться» → тип: **самозанятый**.
3. Приложение попросит: ФИО, паспорт, СНИЛС (если используете Госуслуги — подтянется само).
4. В конце: «Вы стали самозанятым» — **сфотографируйте/сохраните** подтверждение (придёт в кабинете приложения).
5. Открыть **yookassa.ru** → «Подключиться» → выберите «Самозанятые» → введите свои данные (ИНН) → отправьте заявку.
6. Ждём 1–5 рабочих дней (напишут на почту). **Пока ждём — работаем дальше, всё будет в тестовом режиме.**

✅ **Проверка:** в «Мое налоге» статус «действует»; на почте — письмо от ЮKassa (хотя бы «заявка принята»).

### Шаг 1. Покупаем ДВА VPS (40 минут, компьютер, ~700–1000 ₽/мес всего)

**Зачем:** сервис живёт на двух серверах. Так мы соблюдаем закон 152-ФЗ: **персональные данные клиентов (база, логины, оплаты) хранятся в России**, а сам VPN — за границей (там он и должен быть).

| Сервер | Что живёт | Где | Цена |
|---|---|---|---|
| **РУС (сайт)** | сайт, база клиентов, TG-бот, админка | Россия | ~150–300 ₽/мес |
| **DE (VPN)** | только VPN (3x-ui/xray) | Германия | ~400–700 ₽/мес |

⚠️ **Главный критерий: провайдер НЕ ТРЕБУЕТ ДОКУМЕНТЫ** (достаточно телефона и почты).

**① Русский сервер (сайт + база):**
1. **timeweb.cloud** (подойдут также Beget или reg.ru — все принимают оплату из РФ): «Регистрация» (телефон + почта, код в SMS).
2. Создать **Cloud VPS**: регион **Россия**, конфигурация **1–2 vCPU / 2 GB RAM / 30–40 GB SSD**, ОС **Ubuntu 24.04** (если нет — 22.04).
3. Оплата — **МИР или СБП**.

**② Немецкий сервер (только VPN):**
1. **aeza.net** ⭐ (регистрация email + телефон, документов не просят):
   - пополнить баланс **СБП или МИР** (500–1000 ₽ хватит; оплата почасовая — сгорает за реальное время);
   - «Создать VPS»: **локация Германия**, **2 vCPU / 4 GB RAM / NVMe** (~400–700 ₽/мес), ОС **Ubuntu 24.04**;
   - имя: `sonic-vpn`.
2. Запасной вариант, если вдруг что-то не так: **VDSina (vdsina.ru)** — Амстердам, МИР/СБП, тоже без документов.
   (AdminVPS отпал — требует документы.)

📝 **Запишите в заметки (нужны в шагах 2, 3, 5, 6):**
```
RU-сервер (сайт):  IP: 92.118.1.1         пароль root: ********
DE-сервер (VPN):   IP: 185.14.23.107      пароль root: ********
```

✅ **Проверка:** в кабинетах обоих провайдеров серверы «в сети», IP отображаются.

> 💡 Почему два сервера, а не один? Одностраничная выгода: юридическая чистота (данные в РФ)
> + если РКН когда-нибудь доберётся до немецкого IP — сайт и база клиентов останутся живы.
> Дороже всего на ~200 ₽/мес.

### Шаг 2. Учимся «входить» на VPS (5 минут)

**Зачем:** дальше все команды (установка программ, запуск сайта) мы будем печатать «внутри» серверов через SSH. Делаем это **для обоих серверов** (RU и DE из шага 1) — можно открыть два окна PowerShell.

**На Windows 10/11:**
1. Нажмите клавишу **Win** (с логотипом Windows) → начните печатать `powershell` → нажмите Enter. Откроется синее окно — это терминал.
2. Впишите (IP RU-сервера из шага 1) и нажмите Enter:
   ```
   ssh root@92.118.1.1
   ```
3. Первый раз спросит `Are you sure you want to continue connecting?` → впишите `yes` → Enter.
4. `Password:` → введите пароль root **НЕВИДИМО** (ничего не светится, это нормально) → Enter.
5. Появилась строка вида `root@sonic1:~#` — **вы внутри сервера**. Отлично. Повторите те же 4 действия во втором окне для DE-сервера (его IP и пароль).

**На Mac/iPhone (терминал):** та же команда `ssh root@185.14.23.107`.

> Выйти из VPS: вписать `exit`.
> Не работает / «Connection refused» → перезагрузите сервер в кабинете провайдера, попробуйте через минуту.

✅ **Проверка:** вы видите приглашение `root@...:~#` — это значит, что SSH работает.

### Шаг 3. Ставим необходимое скриптами (15 минут)

**Зачем:** на каждом сервере свой набор программ. Из нашего репозитория есть два готовых скрипта — их надо скопировать и запустить на соответствующих серверах.

**3.1. На РУССКОМ сервере** (вы в его SSH, окно №1 из шага 2):
1. На компьютере открыть: **https://github.com/samagon90/vpnStar/blob/arena/01a05219-vpnstar/deploy/vps-setup-ru.sh**
2. Кнопка **«Copy raw file»** (справа сверху) — текст скрипта в буфере.
3. На сервере: `nano /root/vps-setup.sh` → Enter → вставить (на Windows — **правая кнопка мыши** в окне PowerShell) → `Ctrl+O` → Enter → `Ctrl+X`.
4. Запустить:
   ```
   bash /root/vps-setup.sh sonicvpn.ru
   ```
5. Ждём **5–10 минут**. Ставится: Caddy (HTTPS-сертификаты), Node.js 22, pm2, firewall, защита SSH, swap.

**3.2. На НЕМЕЦКОМ сервере** (окно №2, его SSH):
1. Скопировать: **https://github.com/samagon90/vpnStar/blob/arena/01a05219-vpnstar/deploy/vps-setup-de.sh** → «Copy raw file» → на сервере так же сохранить в `/root/vps-setup.sh` (`nano` → вставить → `Ctrl+O` → Enter → `Ctrl+X`).
2. Запустить, подставив **IP российского сервера** (тогда панель 3x-ui будет видна только с нашего RU-сервера — никто чужой не подберёт):
   ```
   bash /root/vps-setup.sh 92.118.1.1
   ```
   (92.118.1.1 — ваш IP RU-сервера из шага 1!)
3. Ждём **5–10 минут**. Ставится: 3x-ui (VPN-панель), firewall, защита SSH, swap.
   При установке 3x-ui установщик может задавать вопросы (порт, логин, пароль) — на каждый просто жмите **Enter** (подойдут значения по умолчанию). В конце он **напечатает адрес панели, логин и пароль** (строка «X-UI installation was successful, Panel: http://IP:порт, username: ..., password: ...») — в потоке строк. Не успели поймать → выполните на DE-сервере:
   ```
   x-ui settings
   ```
   (Пароль утерян совсем: `x-ui reset` — напечатает новый.)

📝 **Запишите (нужны в шаге 4 и в .env шага 6):**
```
Панель 3x-ui (на DE-сервере):  http://185.14.23.107:2053   (URL с портом)
Логин панели:  xxx
Пароль панели: yyy
```

> ⚠️ Сразу после первого входа в панель 3x-ui **смените логин/пароль** (Settings → Modify password) и запишите новые.

✅ **Проверки:**
- в браузере компьютера `http://185.14.23.107:2053` (ваш URL) → открылась страница входа 3x-ui;
- на RU-сервере `node -v` печатает `v22...`.

### Шаг 4. Настраиваем VPN в 3x-ui (20 минут)

**Зачем:** 3x-ui установлен **на немецком сервере**, но «ключи» для подключения людей ещё не созданы. Делаем два сервера подключения: основной (VLESS+Reality — не блокируется) и запасной (Hysteria2 — быстрый).

В панели 3x-ui (адрес из шага 3.2 — `http://IP_DE_СЕРВЕРА:порт`):

1. **Основной сервер:**
   - Меню слева: **Inbounds → Add Inbound** (кнопка сверху).
   - **Protocol:** `vless`
   - **Port:** `443`
   - **Security:** `reality`
   - Внизу откроется блок **Reality Settings**:
     - Рядом с **Private Key** нажмите кнопку **Generate** (сгенерировать).
     - Соседнее поле **Public Key** заполнится само — **скопируйте этот Public Key** (он понадобится в .env, шаг 6).
     - **SNI:** впишите `www.microsoft.com`
     - **Short ID:** можно пустым
     - **Spider Path:** `/`
   - В блоке **Settings → Clients** нажмите **Add Client** — появится клиент с авто-сгенерированным ключом (id/email). Это «образец» — по нему вы протестируете.
   - **Save**.

2. **Запасной сервер:**
   - **Inbounds → Add Inbound**
   - **Protocol:** `hysteria2`
   - **Port:** `8443`
   - **Security:** `none`
   - **Settings → Clients → Add Client**
   - **Save**.

3. **Тест из России (с телефона):**
   - Телефон: установите **v2rayNG** (Android, Play Store) или **Streisand** (iOS).
   - В панели 3x-ui: Inbounds → ваш vless → **Settings → Clients → у первого клиента — иконка QR** → отсканируйте камерой телефона прямо в v2rayNG («Импорт из камеры»).
   - В v2rayNG нажмите на профиль → **подключить**.
   - Откройте YouTube. **Работает — узел живой.** 🎉

📝 **Запишите (в .env, шаг 6):**
```
Public Key (Reality):  PBkAbC...   ← из шага 4.1
```

✅ **Проверка:** YouTube/Google открываются на телефоне через VPN.

### Шаг 5. Домен + Cloudflare (20 минут, ~250 ₽/год)

**Зачем:** красивый адрес сайта + защита от блокировок + быстрая работа в РФ.

**5.1. Покупаем домен:**
1. **reg.ru** → в поиске доменов введите `sonicvpn.ru` → если «свободен» → в корзину → оплата **СБП/картой РФ** (~250–350 ₽/год).
2. Заодно возьмите запасной: `sonic-vpn.com` (~350 ₽/год). Зачем: если .ru когда-нибудь заденут — переключимся за 5 минут.

**5.2. Подключаем Cloudflare:**
1. **dash.cloudflare.com** → **Sign up** (бесплатно, email + пароль).
2. **Add a site** → впишите `sonicvpn.ru` → план **Free** → Continue.
3. Cloudflare покажет **NS-записи** — две строки вида:
   ```
   anna.ns.cloudflare.com
   bob.ns.cloudflare.com
   ```
   (имена будут другие — свои). **Скопируйте обе.**
4. Вернитесь в **reg.ru** → ваш домен → **Управление доменом → Nameservers** → «Изменить» → впишите две строки из Cloudflare → сохранить.
5. Ждём, пока Cloudflare напишет на почту «Active» (от 10 минут до пары часов; можно проверить статус на странице домена в Cloudflare).

**5.3. DNS-записи в Cloudflare** (страница **DNS → Records**):
Нажмите «Add record» и создайте **две** записи:

| Type | Name | Content | Proxy status |
|---|---|---|---|
| `A` | `sonicvpn.ru` | **IP РУССКОГО сервера** (шаг 1) | 🟠 **Proxied (вкл)** |
| `A` | `api.sonicvpn.ru` | **IP РУССКОГО сервера** | 🟠 **Proxied (вкл)** |

> 🟠 оранжевое облако = «прокси» — Cloudflare стоит между посетителем и сервером (заслоняет и ускоряет). Обе записи — оранжевые.
> ⚠️ **DE-сервер (VPN) в DNS НЕ прописываем** — приложения клиентов будут подключаться к нему напрямую по IP (Cloudflare VPN-трафик ломает).

✅ **Проверка:** через 5–15 минут в терминале:
```
curl -I https://sonicvpn.ru
```
Пока сайт ещё не развёрнут — может быть «connect: refused» или 502. Это **нормально** — домен уже работает, сайт появится в шаге 6. Если `curl` говорит «could not resolve host» — подождите ещё (DNS распространяется до часа).

## Часть 3. Частые проблемы (и что делать)

| Симптом | Причина → решение |
|---|---|
| `ssh: Connection refused` | VPS ещё поднимается (первый раз до 10 мин) или упал → перезагрузите в кабинете провайдера |
| `Permission denied (password)` | Ошиблись паролем root → в кабинете провайдера: «Сбросить пароль» → новый пароль |
| Порт 3x-ui не открывается в браузере | Firewall провайдера закрывает нестандартные порты → в кабинете VPS откройте нужный порт (например 2053/tcp) в firewall-правилках |
| `curl: could not resolve host sonicvpn.ru` | DNS ещё «разлетается» (до 1–2 ч) → подождать; проверить, что NS у reg.ru именно Cloudflare |
| Сайт не открывается, `502/503` | Сервис ещё не запущен или падал → `pm2 status`, `pm2 logs sonicvpn` — читать последнюю ошибку |
| SSL: «not secure» сразу после деплоя | Caddy ещё выпускает сертификат (5–15 мин) → подождать; потом — зелёный замок |
| YouTube не грузится через VPN | Проверьте: порт 443 открыт, Public Key в .env совпадает с панелью, SNI = `www.microsoft.com` |
| Бот молчит | `TG_BOT_TOKEN` пустой/с ошибкой → проверить `.env`, `pm2 restart sonicvpn`; в BotFather → API URL должен быть `https://sonicvpn.ru` |
| Кнопка «Войти через Telegram» не работает | Не задан API URL у бота (шаг 7.1.4) или `TG_BOT_TOKEN` пустой |
| Оплата не активирует подписку | Webhook не сохранён/URL с опечаткой → проверить в ЮKassa; `pm2 logs` — строка `[webhook] payment ... paid` |
| `429` от Groq в логах | Лимит бесплатных запросов исчерпан → бот сам ответил по FAQ; спросит клиент — перезадать через минуту; запасной провайдер — OpenRouter |
