## Шаг 0 · Самозанятость (стартуем СЕГОДНЯ, 15 минут)

1. Приложение **«Мой налог»** → зарегистрироваться как самозанятый (НПД). Налог 4% с оплат физлиц, потолок 2,4 млн ₽/год — на старте не упрётесь.
2. Сразу подать заявку на **ЮKassa** (yookassa.ru → самозанятые подключаются онлайн). Одобрение до 5 рабочих дней — поэтому начинаем сегодня, а не в день запуска.
3. Пока ждёте — всё остальное разворачивается в тестовом режиме (`PAYMENT_MODE=mock`).

## Шаг 1 · VPS (30 минут, ~300–600 ₽/мес)

> Оплачивается **картой РФ (МИР) или СБП** — это ключевое требование.

1. **AdminVPS.ru** (альтернатива: Timeweb Cloud):
   - Локация: **Германия** (Frankfurt). Второй узел (резерв, позже) — Нидерланды/Финляндия.
   - Конфиг: **Ubuntu 24.04, 2 vCPU, 4 GB RAM, 40–60 GB NVMe**.
   - При оплате: включить **автоплатёж по МИР** (сервер не отключится, если забудете).
2. Запомнить/записать: **IP-адрес VPS**, логин root (или SSH-ключ).
3. Проверить доступ: `ssh root@IP_ВПС`

> 💡 Есть **зарубежная** карта? Можно бесплатно: Oracle Cloud Always Free (4 ядра ARM / 24 GB / 10 ТБ, ДЦ Frankfurt/Amsterdam). Всё ниже идентично — просто другой VPS.

## Шаг 2 · Подготовка VPS (15 минут)

```bash
# с любого компьютера:
scp deploy/vps-setup.sh root@IP_ВПС:/root/

# на VPS:
ssh root@IP_ВПС
bash /root/vps-setup.sh sonicvpn.ru     # ваш будущий домен
```

Скрипт поставит: **3x-ui** (панель VPN), **Caddy** (авто-SSL Let's Encrypt), **UFW** firewall, fail2ban, Node.js 22, pm2, swap.
В конце — URL панели 3x-ui (логин/пароль сгенерирует, они в выводе скрипта).

## Шаг 3 · 3x-ui: VPN-профили (20 минут)

Зайдите в панель 3x-ui → **Inbounds → Add**:

1. **VLESS + Reality (основной):**
   - Тип: `vless`, транспорт: `tcp`, безопасность: `Reality`
   - Кнопка генерации ключей → **запишите Public Key** (нужен в .env)
   - SNI: `www.microsoft.com`, Flow: `xtls-rprx-vision`
   - Порт: `443`
2. **Hysteria2 (запасной, UDP):** порт `8443` (ключ CA — тоже запишите)
3. Firewall панели: разрешите 443/tcp+udp, 8443/udp

**Быстрый тест из России:** в v2rayNG/Streisand импортируйте любой сгенерированный клиент (панель → Clients) → YouTube открывается → узел работает.

## Шаг 4 · Домен + Cloudflare (20 минут, ~250 ₽/год)

1. **reg.ru** (или beget): купите **sonicvpn.ru** (оплата СБП) + запасной **sonic-vpn.com**.
2. **Cloudflare** (бесплатно): добавьте оба домена, смените DNS-серверы у регистратора.
3. Записи для sonicvpn.ru:
   - `A` | `sonicvpn.ru` | IP VPS | **прокси ВКЛ** (оранжевое облако)
   - `A` | `api.sonicvpn.ru` | IP VPS | **прокси ВКЛ**
   - `A` | `node2.sonicvpn.ru` | IP VPS #2 | **прокси ВЫКЛ** (только DNS — чтобы CF не трогал UDP-трафик VPN)
4. С этого момента сайт доступен в РФ напрямую, а реальный IP VPS скрыт за Cloudflare.

## Шаг 5 · Деплой сайта и панели (20 минут)

На VPS:
```bash
git clone -b arena/01a05219-vpnstar https://github.com/samagon90/vpnStar.git /opt/sonicvpn
cd /opt/sonicvpn/server
npm install
cp .env.example .env
nano .env
```

**`.env` — что вписать** (комментарии уже в `.env.example`):

| Переменная | Что положить |
|---|---|
| `BASE_URL` | `https://sonicvpn.ru` |
| `SECRET_KEY` | `openssl rand -hex 32` |
| `PAYMENT_MODE` | пока `mock`, после ЮKassa — `yookassa` |
| `YOOKASSA_SHOP_ID` / `YOOKASSA_SECRET_KEY` | из кабинета ЮKassa (шаг 8) |
| `TG_BOT_TOKEN` | токен от BotFather (шаг 6) |
| `TG_CHANNEL_URL` | `https://t.me/sonicvpn_channel` |
| `AI_API_BASE` / `AI_API_KEY` / `AI_MODEL` | Groq (шаг 7) |
| `XUI_BASE` | адрес 3x-ui с порта (см. вывод vps-setup.sh) |
| `XUI_USER` / `XUI_PASSWORD` | логин/пароль панели 3x-ui |
| `XUI_HOST` | `sonicvpn.ru` |
| `XUI_PORT` | `443` |
| `XUI_SNI` | `www.microsoft.com` |
| `XUI_PUB_KEY` | **Public Key из шага 3** |
| `ADMIN_TOKEN` | `openssl rand -hex 16` (для возвратов) |

Запуск:
```bash
pm2 start src/index.js --name sonicvpn
pm2 save && pm2 startup        # автозапуск после перезагрузки VPS
curl -I https://sonicvpn.ru/api/health   # → {"ok":true,...} (SSL выдаст Caddy сам за ~5 мин)
```

## Шаг 6 · Telegram-бот (30 минут, 0 ₽)

1. **@BotFather** → `/newbot` → имя `Sonic VPN`, username **sonicvpn_bot** → токен → `TG_BOT_TOKEN`.
2. BotFather → `/mybots` → *Bot Settings → API URL* → `https://sonicvpn.ru` (для кнопки «Войти через Telegram»).
3. Создайте **канал** (username `sonicvpn_channel`) — новости/статусы. Ссылка уже в футере сайта и боте.
4. `pm2 restart sonicvpn` → бот в меню «❓ Поддержка» уже отвечает (FAQ-режим или нейросеть, если есть ключ).

## Шаг 7 · Бесплатная нейросеть для поддержки (5 минут, 0 ₽)

1. **console.groq.com** → войти (email/GitHub/Google, **карта не нужна**) → *API Keys* → `gsk_...`
2. В `.env`:
   ```
   AI_API_BASE=https://api.groq.com/openai/v1
   AI_API_KEY=gsk_...
   AI_MODEL=llama-3.3-70b-versatile
   ```
3. `pm2 restart sonicvpn`
4. Тест в боте: «❓ Поддержка» → «До когда действует моя подписка?» — бот отвечает вашими реальными данными (читает из своей БД). Бесплатно ~1000 вопросов/день. Запасные: OpenRouter `:free`, Gemini (см. `deploy/README.md` шаг 4.1).

## Шаг 8 · ЮKassa (когда одобрят самозанятость)

1. В кабинете ЮKassa: **Shop ID + Secret Key** → `.env` (`YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`, `PAYMENT_MODE=yookassa`, `YOOKASSA_IS_SANDBOX=false`).
2. **Webhook**: URL `https://sonicvpn.ru/api/webhooks/yookassa`, события `payment.succeeded` + `payment.canceled` (токен = ваш Secret Key — проверка уже в коде).
3. `pm2 restart sonicvpn`.
4. Тест: реальный платёж 1 ₽ по СБП → подписка/устройство начисляются автоматически → в истории — строка с бонусом рефереру (если реферер есть).
   Комиссия: СБП **0,4%**, карты ~3,5%. Чеки 54-ФЗ — ЮKassa сам.

## Шаг 9 · Чек-лист боевого запуска (1 час)

- [ ] `https://sonicvpn.ru` открывается в РФ без VPN (проверить с телефона на мобильном интернете)
- [ ] Регистрация: логин+пароль, **без** почты/номера → сразу 7 дней пробника
- [ ] Кабинет: QR «Основного» устройства → импортировать в v2rayNG → YouTube работает
- [ ] «Добавить устройство» (2-е) → QR → подключается с другого телефона
- [ ] 3-е устройство — кнопка «Купить +1 — 99 ₽» (СБП)
- [ ] Заблокировать 2-е устройство → оно не подключается → «Включить» → снова работает
- [ ] Оплата тарифа 199 ₽ по СБП → подписка продлилась, в истории «оплачен»
- [ ] Второй аккаунт по вашей реферальной ссылке → его оплата → вам 20% на баланс
- [ ] Бот: `/start` → «📶 Моя подписка» → QR; «📱 Мои устройства»; `/devices`, `/block 1`, `/unblock 1`
- [ ] Поддержка в боте отвечает на «Сколько стоит 3 месяца?» и «До когда моя подписка?»

## Шаг 10 · Второй узел (резерв) — когда пойдут продажи

Повторить шаги 1–3 на VPS в Нидерландии/Финляндии (~400–600 ₽/мес).
Своим клиентам — на выбор (2-я страна = страховка от блокировки IP первого узла).
Добавить в `.env` отдельный `XUI_BASE` на VPS #2 (v2: кнопки переключения узлов).

## Эксплуатация (обычный уход)

- **Автоплатёж VPS** включён у провайдера — просто не смотрите на баланс.
- Бэкап раз в неделю: `tar czf /opt/sonicvpn-backup.tgz /opt/sonicvpn/data /opt/sonicvpn/server/.env` → перенести на disk/другой VPS.
- `pm2 status` — здоровье; логи: `pm2 logs sonicvpn`.
- **Заблокировали IP узла** (бывает, это норма рынка): новый IP у провайдера (бесплатно/дёшево) → `XUI_HOST` в `.env` → `pm2 restart` → бот/письмо клиентам: «новый профиль в кабинете».
- **Смена логотипа**: заменить файл `public/img/logo.png` на VPS (или в репо) — и всё.
- **Правка текстов** (цены, FAQ бота): `server/src/config.js` (цены), `server/src/ai.js` (база знаний бота) → `pm2 restart`.
