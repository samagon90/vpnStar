# Анализ рынка: 24hype.ru (HypeVPN) + конкуренты

> Документ: разбор эталона (24hype.ru), обзор аналогичных сервисов и список «лучшего из лучшего», которое берём в свой сервис.
> Дата анализа: 30.08.2026

## 1. Эталон: 24hype.ru (HypeVPN)

Молодой российский VPN-сервис. Простой PHP-сайт + Telegram-бот. Вот весь набор его фишек:

### Лендинг (главная страница)
- 3 тарифа в карточках: **1 мес — 249 ₽**, **3 мес — 699 ₽** (🔥 «самый популярный»), **6 мес — 1399 ₽**
- Блок из 4 преимуществ: Онлайн-доступ, Полная приватность (No-Logs), Высокая скорость, Глобальное покрытие (Европа, США, Азия)
- Блок новостей (обновления сервиса) — отличает от 90% конкурентов, создаёт «живой» сервис

### Регистрация и аккаунт
- Регистрация: email + пароль + опциональный реферальный код
- Восстановление пароля через email (кнопка «Забыл пароль»)
- Личный кабинет:
  - «Моя подписка» (сроки, продление, расширение)
  - **Управление устройствами**: список активных устройств, удаление, переименование («Мой телефон», «Ноутбук сына»), дата последнего подключения
  - Настройки email-уведомлений об окончании подписки: за 5 / 2 / 1 день

### Подписки и устройства
- **Стандарт** — 2 устройства одновременно
- **Семейная** — 5 устройств
- Лимит: если попытаться подключить лишнее устройство — оно блокируется; ранние устройства имеют приоритет
- **Неограниченное расширение** подписки: +1 устройство = ½ месячного тарифа, +2 = полный месячный тариф (через кабинет или бота)

### Telegram
- Бот сервиса: управление подпиской и устройствами, оплата
- Отдельный Telegram-чат поддержки

### Реферальная программа
- Реферальный код при регистрации
- Награда: **процент со ВСЕХ оплат** приглашённого (продления + докупки устройств) — не только с первой

### Надёжность / устойчивость к блокировкам
- **Второй домен** hypevpn.app («при включённом впн откройте этот — для стабильного соединения») — прямой ответ на блокировку основного .ru домена

### Юрлицо-обвязка
- Политика конфиденциальности и пользовательское соглашение с датой ревизии (privacy-2026-07-16.php, terms-...)

### Слабые стороны 24hype (что мы сделаем лучше)
1. Сайт выглядит шаблонно/скромно (эмодзи вместо иконок, простая вёрстка)
2. Нет пробного периода — только прямая оплата
3. Нет гарантии возврата
4. Нет явной информации о протоколах и локациях (пользователь не понимает «что ему продают»)
5. Оплата, судя по всему, только картой РФ (СБП не заявлен)
6. Базово 2 устройства — мало на фоне конкурентов (5–10, у Blanc безлимит)

### Общие рыночные паттерны 2026
1. **Telegram-first** — покупка, ключи, продление, подарки прямо в боте (80% аудитории сидит в TG)
2. **Протоколы**: VLESS + XTLS-Reality — главный («не блокируется»), Hysteria2 — скорость, AmneziaWG/WireGuard — запасные. Один сервер держит несколько протоколов параллельно
3. **Свои мобильные приложения практически не у кого из РФ-сервисов** — все выдают готовые конфиги для публичных клиентов: v2rayNG, Streisand, Hiddify, WireGuard, Amnezia, WG Tunnel. Собственное приложение = сложная модерация сторов + риск блокировки
4. **Оплата**: СБП (QR) становится нормой + карты МИР + крипта + Telegram Stars. Эквайринг: ЮKassa, Robokassa, ПСБ
5. **Пробный период** — обязательный хук: 3–7 дней бесплатно, либо «5 дней за 1 ₽»
6. **Устройства**: тренд на 5–10, у премиума — безлимит
7. **Фирменные логистики**: «YouTube без рекламы» (выделенные сервера ЕС), «Белые списки (LTE)» (усиленная маскировка для операторов), профиль для Smart TV
8. **Гарантия возврата** 3–30 дней — признак уверенности
9. **No-logs** заявляют все, доверяют те, кто публикует аудит (Amnezia) или open-source код

## 4. Своя специфика (контекст РФ, 2026)
1. **Хостинг — только за рубежом**: юрисдикция без давления (DE/NL/GB/TR/AE) + маршруты к РФ с низкими пингами
2. **СБП обязателен**: у пользователя должны уходить деньги напрямую из банковского приложения (Сбер, Т-Банк, ВТБ…) по QR — без «карты иностранного банка»
3. **Сайт на CDN с .ru доменом**: Cloudflare прячет origin от РКН, сам домен — быстрый в РФ
4. **Клиенты без Play/Store-зависимости**: APK + .ipa + конфиги, бот присылает всё готовое
