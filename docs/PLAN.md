# Sonic VPN — концепция VPN-сервиса

> Собственный VPN-сервис **Sonic VPN**: хостинг за рубежом (оплата из РФ картой МИР/СБП), приём денег от клиентов по **СБП**, вся инфра ~500–1 200 ₽/мес.
> Базируется на анализе из `docs/ANALYSIS.md` (24hype.ru + конкуренты).

---

## 1. Позиционирование

**Sonic VPN** — быстрый и надёжный VPN для РФ: подключение за 2 минуты через Telegram, оплата по СБП одним QR, 7 дней бесплатно.

- Аудитория: пользователи РФ, которым нужен YouTube/Instagram/AI-сервисы без замедлений
- Килл-фичи: **0 ₽ за 7 дней** · **СБП** · **2 устройства (до 10 за доплату)** · **YouTube без рекламы** · **no-logs**
- Тон: технически честный (показываем протоколы, локации, статусы) — в отличие от шаблонных лендингов

## 4. Инфраструктура: зарубежный хостинг, оплата из РФ

> Ключевое ограничение: **платёж за хостинг идёт из России** — только карты РФ (МИР/Visa/MC) и СБП.
> Зарубежные провайдеры (Hetzner, DigitalOcean, Vultr) с российской картой не оплатить → их исключаем из плана.

### Схема

```
Пользователь (РФ)
   │  СБП QR / карта
   ▼
ЮKassa (0,4% СБП) ──webhook──► ПАНЕЛЬ (Node.js) ──API──► 3x-ui на VPS (Германия/Нидерланды)
   ▲                              │  │
   │                              ▼  ▼
Сайт за Cloudflare (CDN РФ OK)   Бот Telegram (Bot API, 0 ₽)
   ▲
Домен .ru (~200–350 ₽/год, оплата СБП у регистратора)
```

### Деплой (пошагово)
Полная инструкция с командами — в [`deploy/README.md`](../deploy/README.md) + скрипт подготовки VPS [`deploy/vps-setup.sh`](../deploy/vps-setup.sh).

Коротко:
1. Купить VPS (AdminVPS DE / Timeweb Frankfurt, Ubuntu 22.04/24.04, оплата МИР/СБП)
2. `bash deploy/vps-setup.sh` → ставит 3x-ui, Caddy, firewall
3. В панели 3x-ui: создать inbound VLESS+Reality + Hysteria2, выписать публичный ключ
4. Задеплоить панель (Node) на тот же VPS, заполнить `.env` (XUI_BASE, YOOKASSA_*, TG_BOT_TOKEN)
5. Домен sonicvpn.ru → Cloudflare (A-запись → IP VPS, прокси ВКЛ) — сайт работает в РФ без VPN, origin скрыт

### Защита от блокировок IP (стандарт рынка)
- Несколько портов и протоколов на каждом узле (Reality маскируется под TLS-сайт)
- 2 узла в разных странах/провайдерах + докупка IP у провайдера (дешёвая опция)
- Бот умеет «пересадить» пользователя на другой узел одним сообщением
- Ротация портов/сni-домена Reality (скрипт на VPS)

## 5. Оплата по СБП — как это будет работать

### Вариант А (рекомендуемый): ЮKassa
1. Статус: **самозанятый** (НПД, регистрация в приложении «Мой налог» за 15 минут; налог 4% с физлиц; потолок 2,4 млн ₽/год — это ≈ 9000+ клиентов по 199 ₽/мес, на старте неактуально)
2. Подключаем ЮKassa (онлайн, без визитов): способы — **СБП (комиссия 0,4%, максимум 1500 ₽ с платежа)**, карты МИР/Visa/MC (3,5%)
3. ФLOW:
   - Пользователь: «Купить 3 месяца» в боте / на сайте → ЮKassa генерирует **QR-код СБП** (или список банков)
   - Пользователь сканирует QR в приложении банка (Сбер/Т-Банк/ВТБ/200+) → платит
   - Webhook ЮKassa → панель → 3x-ui API создаёт профиль/подписку (или продлевает) → бот шлёт готовый QR/конфиг
   - Возврат (гарантия 3 дня) — один клик через API ЮKassa
4. Чек 54-ФЗ отправляется автоматически (требование к самозанятым — ЮKassa решает сам; приёмы: ~0,4–1,2% при включённой фиче чек-рассылки)

### Вариант Б (запуск за 1 день, без юрлицо)
- Личный **СБП-перевод по номеру телефона** (0% комиссии, лимиты П2П)
- Бот: пользователь переводит сумму на номер, присылает номер телефона отправителя + свой email → оператор/скрипт подтверждает по выписке → выдача
- Минусы: неофициально, без чека, ручной контроль → это только «нулевой» запуск для первых 10–50 клиентов, параллельно регистрируемся самозанятыми и переходим на ЮKassa

### Вариант В (дополнительно, v2)
- Крипта USDT (TRC-20) — 0% комиссии, для тех, кто не любит эквайринг

## 7. Риски и mitigation (честно)

| Риск | Вероятность | Mitigation |
|---|---|---|
| **Юридический**: с 2025 в РФ штрафы за рекламу/предоставление средств обхода блокировок (физлица 30–80 тыс. ₽, юрлица до 500 тыс. ₽ + конфискация) | Средняя | Формулировки на сайте: «безопасное соединение, приватность, доступ к международным сервисам» (НЕ «обход блокировок РКН»); no-logs; сервера за рубежом; работаем через самозанятость с чеками (прозрачность). **Полноценного «ноль риска» на этом рынке нет** — учитываем в цене |
| Блокировка IP узла провайдером | Высокая (это норма) | Несколько протоколов/портов на узле, 2–3 узла в разных странах, пул IP, быстрая «пересадка» из бота |
| Сбой/прекращение работы VPS-провайдера | Низкая | 2 узла у разных провайдеров (AdminVPS + Timeweb), автоплатёж по МИР включён, бэкап конфига 3x-ui + панели — перенос на новый VPS за ~30 мин |
| Блокировка домена .ru РКН | Средняя | Второй домен (pages.dev / .com) + всегда бот как точка входа |
| Потолок самозанятого 2,4 млн ₽/год | Низкая (на год) | Переход на ИП (УСН) — эквайринг тот же |
| 152-ФЗ (персональные данные РФ) | Низкая | No-logs: не храним IP/трафик/историю; email — только логин аккаунта; серверы данных за рубежом |
| Очереди/лимиты СБП у ЮKassa | Низкая | Карты РФ как запасной способ (тот же аккаунт) |
