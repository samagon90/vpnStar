🖥️ Sonic VPN для Windows 10 / 11

Приложение для Windows

Вставь ссылку из Кабинета (или QR) — и приложение само подключится к VPN. Внутри встроенная проверка: работает ли VPN реально, а режим отладки собирает все ошибки — их можно отправить в поддержку одним нажатием.

Как установить — 3 шага

1. Скачай
Нажми синюю кнопку выше. В «Загрузки» появится файл sonicvpn-windows.bat. Это установщик — он скачает всё остальное сам.
2. Двойной клик
Открой файл sonicvpn-windows.bat двойным кликом (в папке «Загрузки»). Окно само скачает нужные файлы (144 МБ, несколько минут) и соберёт приложение. Не закрывай окно до надписи «ГОТОВО».
3. Запусти
На рабочем столе появится ярлык SonicVPN. Двойной клик → вставь ссылку из Кабинета (кнопка «Копировать» у устройства) → «Подключить». Готово: браузеры пойдут через VPN, а зелёные точки в приложении покажут, что всё реально работает. Если Windows спросит про «неизвестное приложение» — нажми «Подробнее» → «Запуск».
🔧 Не заработало? Открой приложение → вкладка «Режим отладки» → «Копировать отчёт» → вставь текст в чат поддержки. По отчёту чиним.
